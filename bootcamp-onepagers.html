Bootcamp One-Pagers

All 16 activities · 17 printable pages

Every bootcamp activity as a sheet you can run off and hand out. Each has a Print button, and every page is verified to fit — nothing spills or gets cut. All are one page except Activity 2, which is two: the 10-skill rating grid on the front, career interests and goals on the back. Print that one double-sided.

These are hard copies, not the packet. The Bootcamp Worksheets packet is all 16 stapled together for a student to keep. These one-pagers are for handing out an activity at a time as you get to it. Same questions, same source — pick whichever fits how you're running the day.
